# AppmovilDos — Primera aplicación Android

Proyecto Android en Java conservado a partir de la aplicación funcional incluida en la actividad.

## Contenido
- Proyecto Gradle/Android Studio completo y ejecutable.
- Actividad principal `MainActivity.java`.
- Recursos y clases Java necesarios para la interfaz.
- `apk/app-debug.apk`: APK ya generado.
- `evidencia/actividad.html` y `evidencia/actividad.pdf`: documentación de la evidencia.

## Requisitos evidenciados
1. Creación del proyecto Android.
2. Creación de la actividad principal.
3. Configuración del proyecto.
4. Programación Java y conceptos de POO.
5. Compilación de la actividad principal.
6. Ejecución de una interfaz Android funcional.

Se excluyen archivos generados por Android Studio/Gradle (.gradle, .idea, local.properties, .DS_Store, .iml) porque no son necesarios para compilar o ejecutar la aplicación.
